# 網拍訂單資料清理示範

這份工作簿展示如何把電商訂單匯出資料整理成可核對的表格。**所有訂單與金額均為合成資料，不是客戶案件。**

[下載 Excel 示範檔](網拍訂單資料清理_合成範例.xlsx)

## 範例做了什麼

- 保留原始匯出資料，整理出獨立的清理結果。
- 找出完全重複的訂單列，保留第一次出現的資料。
- 統一可判讀的日期格式；無效日期保持空白並標記待確認。
- 依示範欄位計算預期入帳，列出與實際入帳的差額。
- 在「異常與處理紀錄」逐項寫下發現、處理方式與待確認事項。

範例原始資料有 8 列；移除 1 列完全重複資料後保留 7 列，其中 3 列需要確認。示範公式只是依本檔欄位計算，實際案件的費用與入帳規則須先由委託方確認。

## 可提供的客製整理

可全程線上處理委託方提供的 Excel／CSV 匯出檔，交付清理後工作簿、異常清單與處理紀錄。小型試作的參考範圍為 1 檔、最多 2 張工作表、2,000 列、15 欄，參考價 **NT$1,500／份**。收到去識別化樣本後，先確認欄位、重複判準、交付日、驗收方式與最終報價；預計 3 天交付。

不需要委託方的賣場登入權限。涉及會計、稅務或平台費率的判斷，應由委託方確認規則後才能套用。

需要私下詢價時，請透過[清序工作室服務網站](https://x213212.github.io/online-data-service/)的 Email 入口，說明檔案類型、約略筆數與希望完成的時間。也可[開啟 GitHub issue](https://github.com/x213212/order-cleanup-demo/issues/new)討論一般性資料格式問題。**請勿在公開 issue 貼真實訂單、個資、密碼或其他機密資料。**
